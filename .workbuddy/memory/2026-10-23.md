## v0.1.4 修复（22:00-22:55）

- **标题页黑屏根因**：`showGame()` 在标题页点「设置/关于/读取」时被误调用，切到空游戏界面。修复：把 `#panelLayer` / `#toast` 从 `#game` 移到 body 级，标题页直接开面板，不再切界面。
- **层级**：标题 `.title-screen` z-index 60，面板层必须 ≥70，否则面板被盖住（曾出现“点设置没反应”）。
- **CSS 括号事故**：用 Python 字符串替换 `.title-screen` 时多写了一个 `}`，Edge 能容错、Electron 直接丢弃后续规则 → 标题背景图丢失（height:0、filter:none）。改 CSS 后务必 `count('{')==count('}')`。
- **移动端适配**：标题改 flex 可滚动；新增 `max-height:600px` / `420px` 两档断点压缩字号与间距；面板/调查中枢/选项用 `calc(100dvh - n)` 限高。
- **APK**：`setLoadWithOverviewMode(false)`（否则整页被缩放出现黑边）；返回键经 `evaluateJavascript` 调 `window.__ZB_back()`，返回 `handled`/`exit`。
- **性能**：字体子集化（tools/subset_font.py，7.9MB→0.95MB）；打字机改 rAF 逐帧；立绘只动 opacity/transform，filter 仅 ≥1000px 桌面启用；背景加已解码缓存；EXE 默认开硬件加速（`ZB_SAFE=1` 回退）。
- **音频“炸麦”真因**：逐帧改 `HTMLMediaElement.volume` 会产生每帧一个台阶的波形跳变。改为 Web Audio：`MediaElementSource → 高通42Hz → 低通14kHz → DynamicsCompressor(-16dB,3:1) → master`，淡入用 `GainNode.linearRamp`；元素 volume 固定 1。BGM_TRIM 0.62 / SFX_TRIM 0.55。注意 attach 时必须补当前轨 gain，否则接管瞬间静音。
- **更新日志**：scripts/data/changelog.js，标题页「更新日志」按钮 + 游戏内菜单，UI.openChangelog()。
- 版本统一到 0.1.4（game.js / package.json / AndroidManifest versionCode=2）。
- 产物：build/out/周日不返校.apk（9.9MB）、build/out/周日不返校-win64.zip（115MB）。

## v0.1.5 —— APK 启动闪退（23:05-23:20）

- **现象**：装好 APK，点图标 0.5 秒黑屏退回桌面（用 ffmpeg/Edge 抽录像帧确认是进程内崩溃，不是白屏）。
- **根因**：`classes.dex` 里只有 `R/R$mipmap/R$string`，**没有 MainActivity**。反查 javac：返回键回调写成了 lambda `value -> {}`，而 javac 用 `-bootclasspath android.jar` 时 classpath 里没有 `java.lang.invoke.LambdaMetafactory` → 编译失败「找不到符号 metafactory」。
- **为什么没被发现**：build-apk.sh 那行是 `javac ... 2>&1 | grep -v "bootstrap class path" || true`，管道 + `|| true` 把非零退出码吞了，`set -e` 失效，继续 d8 打包 R 类，产出"能装不能启"的空壳 APK。v0.1.2 加入返回键逻辑后所有 APK 都是空壳。
- **修复**：lambda 改匿名内部类 `new ValueCallback<String>(){}`；javac 改为 `if ! javac > log 2>&1; then cat log; exit 1; fi`；加两道校验（classes/…/MainActivity.class 存在、dex 里 grep 得到 MainActivity）。
- **加固**：onCreate 先 setContentView 容器再 try/catch 建 WebView，失败时屏幕显示堆栈并写 `getExternalFilesDir()/crash.log`，不再静默退出。
- **铁律**：**Android 壳工程里禁止用 lambda / 方法引用**（android.jar 无 LambdaMetafactory）。要写就写匿名类。
- 版本 0.1.5 / versionCode 3（manifest 与 build-apk.sh 两处都要改）。
- 产物：build/out/周日不返校.apk（9.9MB，dex 含 MainActivity + 3 个匿名类 + StoreBridge，v1/v2/v3 签名均验证通过）。
