## 三、六个 bug 的根因与修法

| # | 现象 | 根因 | 修法 |
| --- | --- | --- | --- |
| 1 | 移动端切后台音乐不停 | 只处理了 `visibilitychange` 的一部分，音频图与 `<audio>` 元素都没有真正挂起 | `audio.suspendAll()`：`AudioContext.suspend()` + 元素 `pause()`，记住当前曲目；回前台 `resumeAll()`，目标轨没有 src 时按 `currentId` 重播 |
| 2 | 最后一条聊天选完，面板直接关掉 | `chatreply` 的回调里直接 `closePanel()` 并推进剧情 | 重写为 `chatExchange`：选完 → 我方消息入列 → 对方消息逐条到达 → 停在面板等「继续」 |
| 3 | 选项选完立刻弹下一个 | 同上，回复后立刻 `next()` | 逐条发送 + 同一会话内续接，不再新开面板 |
| 4 | 做到一半退出重进，选项消失 | `loadChapter` 没有复位 `blocked/paused/typing/waiting` | 载入时统一清场：`ui.closeAll()` + 复位全部交互标志 |
| 5 | 移动端选项贴顶、被裁 | 矮屏用 `align-items:flex-start` + `max-height` | 改居中 + `overflow-y:auto`，`margin:auto 0` |
| 6 | 选项处不能存档 | 存档入口只在调查中枢 | 选项层加 `.choice-tools`（存档 / 菜单），任意选项处可用 |

顺带修的：调查行动内的 `goto` 会跳到章节里同名标签（第三章「罗一舟」行动曾因此跳到主线）。现在行动脚本有独立帧与**局部标签**，`findLabel` 先查局部再查章节。

## 四、AI 接入

**两个使用点**
1. 第二章起的「校园学习助手」对话 —— 系统提示词写成学校口径，答得完整但不把话说死。
2. 第五章「区教育局的网上信箱」收到的那份答复 —— 在线时由模型现写，离线时用内置公文稿。

**兼容性**：统一走 `POST {baseUrl}/chat/completions`，预设 OpenAI / DeepSeek / Moonshot / 智谱 GLM / 通义千问 / Ollama / 自定义。支持 SSE 流式（`data:` 逐块解析）；返回体兼容 `choices[].message.content`、`choices[].delta.content`、`output.text`、`response`。密钥只写本机 `localStorage`（APK 走 `SharedPreferences` 桥），不上传。

**不接 API 也能正常玩**——这一点是硬要求，做了三处兜底：
- 未配置 → 助手走内置规则表，教育局走内置公文稿；
- 请求失败 / 401 / 404 / 429 / 超时 → 捕获后 toast 提示，正文退回内置稿；
- 生成途中玩家读档或退出 → 用 `this.current !== node` 丢弃迟到的响应，不会污染新场景。

**测试**：`node tools/test-bureau.mjs` 起了一个模拟的 OpenAI 兼容服务，覆盖 10 项断言（含流式、失败回退、来源标记），全部通过。

## 八、已知限制

1. **APK 与 EXE 都没能在这个会话里真正启动验证**。打包链路、签名、dex 主类、资源结构、`resources/app` 布局都已校验；`build/www` 也用 `file://` 直接跑过（这是两个壳加载的同一份内容），无页面错误。但这台机器上的命令行环境无法启动 GUI 进程，`周日不返校.exe` 一启动就被环境掐掉，所以「双击能不能开窗」需要你在桌面上试一次。
   - 若打不开，用 `set ZB_LOG=<某个路径>` 再双击，会在该路径写一份启动日志（`main.js loaded` / `app ready` / `window created` / `did-fail-load …`），能直接看出卡在哪一步。
   - APK 白屏则先看 logcat 的 `ZBWeb` 标签。
2. **手机端接第三方接口可能被 CORS 拦**。桌面版正常；手机端失败会退回离线稿，不影响通关。
3. 立绘为成人偶像卡面，与初三学生设定不符（历史遗留的占位素材）。
4. 隐藏结局的数值门槛（沈予安信任 ≥ 60、关键材料 ≥ 7）偏严，需要刻意规划路线才能打到；这是故意设计的，但如果觉得过难，改 `judge.js` 里那两行即可。
5. 无语音、无 CG 鉴赏、无多语言。
