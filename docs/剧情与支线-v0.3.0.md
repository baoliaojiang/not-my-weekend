## 一、这一版做了什么

一句话：**把"旁白讲完一件事"改成"一整个学校的一天"。**

在此之前，主线的推进方式是「事件 → 旁白描述 → 下一事件」。学校是一个背景板，  
活动只是一张表格，角色只在需要说话的时候出现。这一版把学校重新变成一个  
有课表、有早读、有课间、有午休、有晚自习的地方——所有主线信息都挂在这些  
具体时刻上，因此每件事都要花一整个上午才能做完，而"不做"也要花一整个上午。

具体动作：

| 维度     | v0.2.2      | v0.2.3 → v0.3.0                                                                   |
| ------ | ----------- | --------------------------------------------------------------------------------- |
| 主线场景密度 | 7 章共 40 个场景 | 7 章共 60+ 个场景                                                                      |
| 一天的结构  | 「上午四节课」一句带过 | 早读 7:30 → 四节上午课 → 午休 → 五节下午课（14:00–18:20）→ 三节晚自习（19:00–21:50，每节 50 分钟 + 休息 10 分钟） |
| 课堂     | 只有旁白提到      | 6 场可做的随堂小测 + 大量课堂对话                                                               |
| 投诉     | 一句旁白        | 可填写的政务表单 + 受理回执 + 办理进度页 + 12345 逐句通话                                              |
| 角色     | 6 人         | 12 人（v0.3.0 新增保健室校医**傅医生**）                                                       |
| 背景     | 10 张        | 18 张                                                                              |
| 音乐     | 6 首         | 16 首                                                                              |
| 支线     | 1 条《一元口罩》   | **2 条**（《一元口罩》+ 《直饮水》）                                                            |

v0.3.0 相对 v0.2.3 的三处改动：

1. **补上第二条支线《直饮水》**——完整可玩，独立存档，5 种结果（含一个隐藏结局）
2. **补写序章与第五章**——这两章原本明显短于其它章，v0.3.0 把它们补齐到同一量级
3. **修一个存档污染的 bug**——支线二重玩时会继承上一次结局的标记（详见第八节）

## 四、投诉从旁白变成真表单

### 4.1 可填写的政务表单（`govform`）

玩家真的在填一张表，填的东西会带进后面的答复：

- 反映对象（下拉）、问题类型（多选 chips）
- 事发日期、涉及金额
- 正文 textarea（500 字上限，实时计数，**不少于 30 字**）
- 「插入我整理过的事实（n 条）」——把已获得材料一键塞进正文
- 诉求多选、联系人 / 手机号
- **算术验证码**
- 真实性承诺勾选（不勾不能提交）

提交后拿到**受理回执**：编号 `SZ + 日期 + 4 位流水号`（按剧情时间生成，不是系统日期）、  
提交时间、办理单位。再往下是**办理进度页**：每个节点可点开看「节点意见」。

在进度页点「关闭」会走 `formal_close` 支线——**没提交**，文件袋塞回书包。  
这是一个有后果的选择。

### 4.2 12345 是一通真的电话（`hotline`）

拨号 → 接通计时 → 逐句对话，每句给 2–3 种说法：**怎么开口、怎么定性、留不留信息**。  
选择会写进标记（`flags`），后面的办理答复内容跟着变。

### 4.3 渠道顺序（重要）

**不设「教导处代收」这条路。** 顺序是：

```
12345（可匿名）→ 市教育局网上平台（需实名）→ 逐级上行
```

学校内部只有「学校办公室」这一个回应主体，它出现的方式是**教育局转办之后**，  
不是玩家直接递交的对象。第三章里"去教导处被推诿"是**失败经历**：  
「这个你找班主任」→「那你找年级组」→ 年级组门锁着，贴了张纸：外出听课，下午返校。

## 五、支线《一元口罩》

独立存档、独立行动点、独立结局判定，**不写 0 号自动存档位**，进支线不顶掉主线进度。

- 15 个调查行动、6 点行动力，一次最多做 6 件
- 5 种结果：`side_coin`（隐藏）/ `side_partial` / `side_dispute` / `side_done` / `side_flow`
- 判定看的不是选了哪个按钮，而是：材料够不够、批次分没分清、  
  校内和校外两条线有没有都走到、有没有在核实之前把话说到最满
- 新增角色：后勤主任吴建国、小卖部周姨
- 新增材料 M023–M036

支线的节奏与主线一致：**保健室窗口 → 课间 → 午休 → 办公室 → 放学 → 渠道选择 → 三天后 → 结局**，  
不是一串纯对话。

## 六、支线《直饮水》（v0.3.0 新增）

第二条完整支线，独立存档、独立行动点、独立结局判定。

**它的问题和支线一不一样。** 支线一是「有人做了一件事，但没人承认」；  
支线二是「没有人做错事，但也没有人记录」——直饮水机的滤芯超期没换、  
公示编号印错了一个数字、报修登记只有一行「已处理」、孩子喝了半年也没人知道。  
**没有坏人，只有一堆没人签字的表格。**

- 14 个调查行动、8 点行动力，一次最多做 8 件
- 5 种结果：`side_filter`（隐藏《最后一杯》）/ `side_clear2`（换了新的）/  
  `side_partial2`（换了新的，但记录还是空的）/ `side_procedural2`（流程走完了）/  
  `side_dispute2`（三个人在传）
- 4 条渠道分支：真打 12345 / 走市教育局平台 / 校内追问 / 先问清"有人喝过"
- 1 个中段事件：教师办公室有独立饮水机——于是"喝过这水并且没事"这个证据**从来就不存在**
- 新增角色：保健室校医**傅医生**（男，白大褂立绘，从源素材库导出）
- 新增材料 M043–M054，共 12 份

节奏：保健室报修登记 → 后勤查滤芯台账 → 拍公示照片 → 现场看机器 →  
找喝过的人 → 四选一收束 → 结果判定。

隐藏结局《最后一杯》要求：核心三份材料齐 + 有实际证据 + 报修登记 +  
空白维护记录 + 公示上线 + 实测数据 + 至少一条渠道 + 渠道是校内追问 +  
**全程没有把话在班群里说满**。也就是说——查到最后一步，你依然没有公开，  
只是把一张**没人签的空白表**拍在了所有人面前。

## 八、这一版修掉的真问题

1. **音乐炸麦**：16 首 BGM 全是 22.05 kHz / 约 88 kbps 的手游压缩音源，  
   在手机扬声器和蓝牙耳机上二次重采样后劣化明显。全部从源 WAV 重建为  
   44.1 kHz / 192 kbps，`loudnorm=I=-17:TP=-1.5`，播放端 `BGM_TRIM` 0.62→0.34。
2. **快速切歌掉音乐**：交叉淡变的延时回调会 `pause` 正在播的那条轨。加了切歌序号，  
   并在每次切歌时把其它轨增益归零。实测输出峰值 −7.5 dBFS → −14.9 dBFS。
3. **关掉面板后剧情卡住**：`closePanel` 没清空底部按钮区，「新拿到的材料」的  
   「收下」按钮残留，剧情推不动。已修。
4. **聊天流程点不掉**：隐藏/显示继续按钮的代码还在查旧类名 `.chat-continue`，  
   实际元素已是 `.wx-continue`。已统一。
5. **受理编号取系统日期**：2025 年 9 月的案子拿到 2026 年的编号。改为按剧情时间生成。
6. **第三章口径矛盾**：原写「把材料交到教导处」，与后面 12345 路线冲突。已改。

v0.3.0 修掉的：

1. **支线二重玩继承上一轮结局**：支线二的事件标记用的是 `side2_` 前缀，  
   而存档清理表写的是 `['side_']`——`'side2_read_notice'.startsWith('side_')`  
   为 false，所以上一轮打出的标记一个都没清掉。表现是：第一次打出隐藏结局，  
   第二次随便点两下就能"保送"隐藏结局。清理表已改为 `side2: ['side2_']`。
2. **支线二结局 ID 与支线一撞车**：两个支线都用了 `side_clear` / `side_partial` /  
   `side_procedural` / `side_dispute`，导致支线路口的通关记录互相覆盖。  
   支线二改为 `side_clear2` / `side_partial2` / `side_procedural2` / `side_dispute2`。
3. **校医立绘串角色**：支线二原写的保健室校医复用陈老师的立绘，视觉上会以为是同一个人。  
   已从源素材库导出白大褂男性立绘，独立注册为「傅医生」。
4. **现场记录拿不到**：M043 只在两个开场分支给出，导致"看公示"这条线的  
   玩家永远拿不到核心材料。已在该分支补上。
