## 三、后续更新动态模板

用于测试期间发补丁、修问题、加内容时复用。保持同一套口吻：说清楚改了什么，不夸。

```
【初见测试 · 更新】

这次改了这些：
· 
· 
· 

已知但还没解决的：
· 

存档不受影响。遇到新问题还是老地方说。

——
剧情为虚构演绎，与任何真实学校、机构无关。

#不属于我的周末# #初见测试#
```

使用提示：
- 「改了这些」最多列三条，多了没人看。
- 「已知但还没解决的」不要省略。写了这一节，玩家才愿意继续报问题。
- 不要在更新动态里写"大幅优化""全面提升"这类无信息量的词，直接写改了什么。

## 四、发布检查清单

| 检查项 | 要求 |
|---|---|
| 版本号 | 全文不得出现任何版本号（含 `v0.x`、`0.x.x`、构建号） |
| 绝对化表述 | 无「最」「唯一」「彻底」「完美」「全部做完」；「所有人」类词只用于描述场景，不作判断 |
| 免责 | 「虚构演绎 / 与任何真实学校机构无关 / 不代表官方立场 / 仅供娱乐」四项齐全 |
| 适龄提示 | 12 周岁以上，与游戏内标识一致 |
| 无障碍提示 | 闪烁与快速切换的提醒保留 |
| 话题 | 4 个以内，主话题放第一位 |
| 链接 | 游玩地址只放简介，动态里不重复堆链接，避免被折叠 |
| @ 与抽奖 | 不使用。无奖品时不写"抽送" |
